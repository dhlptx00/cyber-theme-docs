Contact form

Send a support request with this form. Include your store URL (for example https://storename.myshopify.com), a description of the problem, and screenshots if you have them.

Form not loading? Open the support form in a new tab or email dhlptx00@gmail.com.

How to contact us

  • Contact form (preferred): the form above, or open it in a new tab.
  • Email: dhlptx00@gmail.com. Use the subject Cyberdeck theme support.

What to include

  1. Your store URL (your-store.myshopify.com), plus the storefront password if the store is password protected.
  2. Theme version. In Online Store › Themes, the version is shown on the theme in your theme library.
  3. The page URL where the problem happens, and the steps to reproduce it.
  4. Screenshots or a short screen recording, plus the browser and device you used.
  5. Any apps or code changes you added to the theme.
Never send your Shopify admin password. If we need to look inside your admin, we'll ask for a collaborator request instead.

What support covers

  • Included: questions about the theme's features and settings, help with the setup steps in the documentation, and fixes for bugs in the theme.
  • Not included: custom design or code changes, third-party apps and their compatibility, and problems caused by edits to the theme code.
  • Updates: new versions are announced in the changelog and delivered as theme updates in your Shopify theme library.
